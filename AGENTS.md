# UI implementation rules

- Read `DESIGN.md` and `design-tokens.json` before changing interface markup or styles.
- Use existing design tokens for colors, typography, spacing, radii, shadows, and motion. Do not invent visual values in HTML, CSS, or JavaScript.
- If a required visual value is missing, propose the token and its reason, then ask the product owner to approve it before using it.
- Keep controls keyboard accessible, visibly focused, labelled, and touch-friendly. Preserve reduced-motion preferences.
- Keep English and Simplified Chinese translations and accessible labels in sync.
- Label sleep, sensor, heat-map, and suggestion content as sample data. Do not present it as live or clinically validated information.
- This Phase 1 concept represents one person. Do not add pet detection or pet-related interpretation.
- This repository is a static prototype. Do not imply it connects to hardware or a production account.
